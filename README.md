Site: https://alexlopespereira.github.io/idp_governodigital/

## Estrutura

- `index.md` — página inicial do site (Jekyll, tema Cayman)
- `pdfs/` — slides das aulas em PDF
- `_config.yml` — configuração Jekyll para GitHub Pages
